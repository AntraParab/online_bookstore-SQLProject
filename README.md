# 📚 Online Bookstore Analytics

An Online Bookstore Analytics project built using PostgreSQL, SQL, Python Flask, HTML, CSS, and JavaScript.

The project analyzes bookstore data including books, customers, orders, sales, and inventory and presents important business insights through an interactive dashboard.

## 🛠️ Technologies Used

- PostgreSQL
- SQL
- Python
- Flask
- HTML
- CSS
- JavaScript
- Chart.js

## 📊 Project Features

- Total number of books
- Total customers
- Total orders
- Total revenue
- Sales analysis by genre
- Top 5 most ordered books
- Customer analysis
- Book and customer data tables
- Interactive dashboard charts

## 🔍 SQL Analysis

The project includes SQL queries to:

1. Find total books sold for each genre
2. Calculate average price of Fantasy books
3. Find customers who placed at least 2 orders
4. Find the most frequently ordered book
5. Find the top 3 most expensive Fantasy books
6. Calculate total books sold by each author
7. Find cities of customers who spent over $30
8. Find the customer who spent the most
9. Calculate remaining stock after fulfilling orders
